# Basic Chatbot

A simple rule-based chatbot written in Python, created for my CodeAlpha Python Programming Internship (Task 4).

## About

The chatbot reads the user's message and replies with a predefined response. It keeps chatting until the user says "bye".

## Features

- Responds to greetings, "how are you", and "bye"
- Extra replies for "your name" and "help"
- Not case-sensitive
- Friendly message for unknown input

## Concepts Used

Functions, if-elif statements, while loops, input/output

## How to Run

1. Install Python 3 from [python.org](https://www.python.org).
2. Download chatbot.py.
3. Run in a terminal: python chatbot.py (or open it in IDLE and press F5).

## Example


You: hello
Chatbot: Hi!
You: how are you
Chatbot: I'm fine, thanks!
You: bye
Chatbot: Goodbye!
